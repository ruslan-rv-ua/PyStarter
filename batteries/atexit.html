Модуль atexit

Модуль atexit надає простий механізм для реєстрації функцій "завершення" (exit functions). Ці функції викликаються автоматично, коли програма завершується звичайним шляхом, наприклад, коли основний скрипт добігає кінця або викликається sys.exit(). Важливою особливістю є те, що ці функції виконуються навіть якщо в основній частині програми виник неперехоплений виняток.

Базове використання

Найпростіший спосіб зареєструвати функцію для виконання при завершенні – це використати декоратор @atexit.register.

import atexit

@atexit.register
def goodbye():
    print("Скрипт завершує роботу. До побачення!")

print("Привіт, світ!")
# Інший код програми

У цьому прикладі функція goodbye буде викликана автоматично після того, як виконається рядок print("Привіт, світ!") і програма дійде до свого природного завершення. Навіть якщо ми не викликаємо goodbye() безпосередньо, atexit подбає про її запуск.

Виконання при винятках в основному коді

Однією з ключових переваг atexit є те, що зареєстровані функції виконуються навіть тоді, коли програма завершується через неперехоплений виняток.

import atexit

@atexit.register
def cleanup_on_exit():
    print("Виконується очищення ресурсів...")

print("Початок роботи скрипта.")
# Симулюємо помилку
raise ValueError("Щось пішло не так!")
print("Цей рядок не виконається.")

Незважаючи на те, що ValueError перерве нормальне виконання скрипта, функція cleanup_on_exit все одно буде викликана перед тим, як інтерпретатор повністю зупиниться. Це робить atexit надійним інструментом для гарантованого виконання критично важливих операцій очищення.

Порядок виконання зареєстрованих функцій

Якщо зареєстровано декілька функцій, вони будуть виконуватися у порядку, зворотному до порядку їх реєстрації (LIFO - Last In, First Out). Тобто, функція, зареєстрована останньою, виконається першою.

import atexit
import time

@atexit.register
def func_a():
    print("Виконується функція A (зареєстрована першою, виконується останньою)")

@atexit.register
def func_b():
    print("Виконується функція B (зареєстрована другою, виконується першою)")

print("Основна частина програми.")
time.sleep(1)
print("Програма завершується.")

Вивід буде таким:

Основна частина програми.
Програма завершується.
Виконується функція B (зареєстрована другою, виконується першою)
Виконується функція A (зареєстрована першою, виконується останньою)

Це важливо враховувати, якщо порядок операцій очищення має значення.

Винятки всередині зареєстрованих функцій

Що станеться, якщо виняток виникне всередині самої зареєстрованої функції? atexit обробляє це досить грамотно: інформація про виняток буде виведена на екран (в sys.stderr), але це не зупинить виконання інших зареєстрованих функцій.

import atexit

@atexit.register
def func_x():
    print("Функція X: все добре.")

@atexit.register
def func_y_with_error():
    print("Функція Y: зараз буде помилка...")
    raise RuntimeError("Помилка всередині func_y_with_error")

@atexit.register
def func_z():
    print("Функція Z: виконується до func_y_with_error.")

print("Запуск скрипта з потенційною помилкою в exit-функції.")

При завершенні скрипта ви побачите повідомлення від func_z, потім повідомлення про помилку з func_y_with_error та її трейсбек, і нарешті повідомлення від func_x. Виконання func_x не буде перервано помилкою в func_y_with_error.

Скасування реєстрації функцій

Іноді може виникнути потреба скасувати реєстрацію функції, щоб вона не виконувалася при завершенні. Для цього існує функція atexit.unregister().

import atexit

@atexit.register
def my_exit_function():
    print("Ця функція не повинна виконатися!")

print("Реєструємо функцію, а потім скасовуємо реєстрацію.")
atexit.unregister(my_exit_function)

print("Скрипт завершується.")

У цьому випадку повідомлення "Ця функція не повинна виконатися!" не з'явиться, оскільки реєстрацію my_exit_function було скасовано.

Програмна реєстрація функцій та передача аргументів

Окрім декоратора, функції можна реєструвати програмно, викликаючи atexit.register() як звичайну функцію. Це також дозволяє передавати аргументи до зареєстрованих функцій.

import atexit

def log_message(level, message):
    print(f"[{level.upper()}] Лог завершення: {message}")

# Реєстрація з позиційними аргументами
atexit.register(log_message, "info", "Програма успішно завершила роботу.")

# Реєстрація з іменованими аргументами
atexit.register(log_message, message="Перевірка файлів перед виходом.", level="debug")

# Можна також передавати аргументи до функцій, що реєструються через декоратор,
# але це робиться через часткове застосування функцій (наприклад, functools.partial)
# або лямбда-функції, оскільки декоратор безпосередньо не приймає аргументи для функції, що декорується.
# Простіший варіант - програмна реєстрація, як показано вище.

print("Основний код програми виконується...")
# Уявимо, що тут відбувається якась робота
print("Завершення основного коду.")
При завершенні скрипта будуть викликані обидві реєстрації log_message з відповідними аргументами, причому та, що зареєстрована останньою (level="debug"), виконається першою.

Важливі обмеження

Незважаючи на свою корисність, модуль atexit має деякі обмеження:

  1. Не викликається при "жорсткому" вбивстві процесу: Якщо програма вбита сигналом, який не обробляється Python (наприклад, SIGKILL), або через фатальну внутрішню помилку Python, зареєстровані функції не будуть викликані.
  2. Не викликається при os._exit(): Функція os._exit(n) завершує процес негайно, без виконання будь-яких операцій очищення, включаючи функції, зареєстровані через atexit. Використовуйте sys.exit() для нормального завершення.

Практичний приклад: Логування часу завершення чат-бота

Уявімо простий ехо-бот, і ми хочемо логувати точний час, коли користувач завершив взаємодію з ним.

import atexit
from datetime import datetime

def log_session_end():
    now = datetime.now()
    print(f"Сеанс чат-бота завершено: {now.strftime('%Y-%m-%d %H:%M:%S')}")

atexit.register(log_session_end)

print("Ласкаво просимо до Ехо-Бота! Введіть 'exit' для виходу.")

while True:
    user_input = input("Ви: ")
    if user_input.lower() == 'exit':
        print("Бот: До побачення!")
        break
    elif user_input.lower() == 'hack': # Приклад для демонстрації винятку
        raise ConnectionError("Спроба несанкціонованого доступу!")
    print(f"Бот: {user_input}")

# Коли цикл завершиться (через 'exit' або виняток, якщо він не фатальний для інтерпретатора),
# функція log_session_end буде викликана.

У цьому прикладі, незалежно від того, чи користувач введе 'exit', чи введе 'hack' (що спричинить ConnectionError), функція log_session_end буде викликана, записуючи час завершення сеансу. Це демонструє, як atexit може допомогти забезпечити виконання важливих завершальних дій.

Резюме

Модуль atexit дозволяє реєструвати функції, які гарантовано виконуються при завершенні програми – як при нормальному виході, так і при неперехоплених винятках (окрім фатальних помилок чи os._exit()). Функції реєструються через декоратор @atexit.register або виклик atexit.register(), виконуються у зворотному порядку реєстрації (LIFO), і можуть бути скасовані через atexit.unregister(). Це робить atexit корисним для задач очищення, логування та збереження стану, забезпечуючи надійне виконання фінальних операцій.
