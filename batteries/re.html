Регулярні вирази

Регулярні вирази (Regular Expressions, RegEx) — це послідовності символів, які формують шаблон для пошуку та маніпулювання рядками. Вони широко використовуються в обробці тексту, пошукових системах для знаходження, заміни та перевірки відповідності текстових рядків.

Існують різні реалізації регулярних виразів у різних мовах програмування та інструментах, але основні концепції та синтаксис залишаються схожими.

Регулярні вирази можуть містити як звичайні літери та цифри, так і спеціальні символи, які називаються метасимволами. Метасимволи дозволяють створювати більш гнучкі та потужні шаблони для пошуку.

Метасимволи (шаблони), які відповідають одному символу:

Метасимвол Пояснення Приклад регулярного виразу Відповідний рядок
[] Визначає набір символів, з яких може бути вибрано один [abc] "a", "b", "c"
[^] Визначає набір символів, які не повинні бути вибрані [^abc] "d", "e", "f"
. Відповідає будь-якому символу, крім символу нового рядка a.b "axb", "a1b", "a b"
\d Відповідає будь-якій цифрі (еквівалентно [0-9]) \d\d "12", "34", "99"
\D Відповідає будь-якому символу, крім цифри (еквівалентно [^0-9]) \D\D "ab", "&%", "!@"
\w Відповідає будь-якій букві, цифрі або символу підкреслення (еквівалентно [a-zA-Z0-9_]) \w\w "ab", "12", "a_"
\W Відповідає будь-якому символу, крім букви, цифри або символу підкреслення (еквівалентно [^a-zA-Z0-9_]) \W\W "&%", "!@", " *"
\s Відповідає будь-якому пробільному символу (пробіл, табуляція, символ нового рядка тощо) \s\s " ", "\t\t", "\n\n"
\S Відповідає будь-якому непробільному символу (еквівалентно [^\s]) \S\S "ab", "12", "!@"
\b Відповідає межі слова (місце, де зустрічаються символ слова та несимвол слова) \bword\b "word" (точно відповідає слову "word")
\B Відповідає місцю, де немає межі слова \Bword\B "sword" (відповідає "word" всередині слова)

Квантифікатори — вказують на кількість повторів:

Квантифікатор Пояснення Приклад регулярного виразу Відповідний рядок
* Відповідає попередньому виразу нуль або більше разів a*b "b", "ab", "aab", "aaab"
+ Відповідає попередньому виразу один або більше разів a+b "ab", "aab", "aaab"
? Відповідає попередньому виразу нуль або один раз a?b "b", "ab"
{n} Відповідає попередньому виразу точно n разів a{3}b "aaab"
{n,} Відповідає попередньому виразу n або більше разів a{2,}b "aab", "aaab", "aaaab"
{n,m} Відповідає попередньому виразу від n до m разів a{1,3}b "ab", "aab", "aaab"
{,m} Відповідає попередньому виразу нуль або більше разів, але не більше ніж m разів a{,3}b "b", "ab", "aab", "aaab"

Жадібність регулярних виразів

За замовчуванням регулярні вирази є "жадібними", тобто вони намагаються знайти найдовшу можливу відповідність. Це означає, що якщо є кілька можливих відповідностей, регулярний вираз вибере найдовшу.

Наприклад, регулярний вираз .* відповідає будь-якій кількості символів, включаючи нуль. Якщо застосувати цей регулярний вираз до рядка "hello world", то він знайде відповідність "hello world", оскільки це найдовша можлива відповідність.

Межі знайденого шаблона

Регулярні вирази також можуть вказувати на межі знайденого шаблона. Це може бути корисно, коли потрібно знайти відповідність лише в певному місці рядка.

Наприклад, метасимволи ^ та $ вказують на початок та кінець рядка відповідно. Регулярний вираз ^hello відповідає рядку "hello", але лише якщо він знаходиться на початку рядка. Регулярний вираз world$ відповідає рядку "world", але лише якщо він знаходиться в кінці рядка.

Іншим прикладом є метасимвол \b, який вказує на межу слова. Регулярний вираз \bword\b відповідає рядку "word", але лише якщо він є окремим словом (тобто, якщо з обох боків є небуквено-цифрові символи або початок/кінець рядка).

Ці конструкції можуть бути використані разом з іншими метасимволами та квантифікаторами для створення більш точних та гнучких шаблонів для пошуку та маніпулювання текстом.

Регулярні вирази в Python

Функції для роботи з регулярними виразами в Python знаходяться в модулі re.

re.search()

Пошук першої відповідності регулярному виразу в рядку.

re.search(pattern, string, flags=0)

Параметри:

  • pattern — регулярний вираз.
  • string — рядок, в якому виконується пошук.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку наприклад, для ігнорування регістру символів).

Повертає:

  • об'єкт Match, якщо знайдена відповідність.
  • None, якщо відповідності не знайдено.

Об'єкт Match містить інформацію про відповідність, включаючи індекси початку та кінця відповідності в рядку, а також саму відповідність.

Деякі корисні методи та властивості об'єкта Match:

  • group() - повертає рядок, який відповідає регулярному виразу.
  • group(n) - повертає n-ту групу в регулярному виразі. Групи визначаються за допомогою дужок () в регулярному виразі.
  • start() - повертає індекс початку відповідності в рядку.
  • end() - повертає індекс кінця відповідності в рядку.
  • span() - повертає кортеж з індексів початку та кінця відповідності в рядку.

Приклад:

>>> import re
>>>
>>> string = "Hello, world!"
>>> pattern = r"(\w+), (\w+)!"
>>> match = re.search(pattern, string)
>>> match.group()
'Hello, world!'
>>> match.group(1)
'Hello'
>>> match.group(2)
'world'
>>> match.start()
0
>>> match.end()
13
>>> match.span()
(0, 13)
>>>
  • відповідність "Hello, world!" знайдена в рядку "Hello, world!".
  • починаючи з індексу 0.
  • закінчуючи індексом 13.
  • перша група в регулярному виразі відповідає рядку "Hello".
  • друга група - рядку "world".

Ще приклад:

>>> string = "Hello, world!"
>>> match = re.search('world', string)
>>> match.group()
'world'
>>> match.span()
(7, 12)
>>>

re.fullmatch()

Перевірка, чи відповідає цілий рядок регулярному виразу.

re.fullmatch(pattern, string, flags=0)

Параметри:

  • pattern — регулярний вираз.
  • string — рядок, який перевіряється.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку (наприклад, для ігнорування регістру символів).

Повертає:

  • об'єкт Match, якщо рядок повністю відповідає регулярному виразу.
  • None, якщо рядок не відповідає регулярному виразу.

Приклад:

>>> import re
>>>
>>> string = "Hello, world!"
>>> pattern = r"(\w+), (\w+)!"
>>> match = re.fullmatch(pattern, string)
>>> match.group()
'Hello, world!'
>>> match.group(1)
'Hello'
>>> match.group(2)
'world'
>>> match.start()
0
>>> match.end()
13
>>> match.span()
(0, 13)
>>>
  • рядок "Hello, world!" повністю відповідає регулярному виразу (\w+), (\w+)!.
  • перша група в регулярному виразі відповідає рядку "Hello".
  • друга група - рядку "world".

Ще приклад:

>>> string = "Hello, world!"
>>> match = re.fullmatch(r'\w+', string)
>>> match is None
True
>>>
  • рядок "Hello, world!" не повністю відповідає регулярному виразу \w+.
  • re.fullmatch() повертає None.

re.split()

Розбиття рядка на частини за допомогою регулярного виразу.

re.split(pattern, string, maxsplit=0, flags=0)

Параметри:

  • pattern — регулярний вираз, за яким буде виконуватися розбиття рядка.
  • string — рядок, який розбивається.
  • maxsplit — необов'язковий параметр, який вказує максимальну кількість розбиттів. За замовчуванням, розбиття виконується по всіх відповідностях регулярного виразу.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку (наприклад, для ігнорування регістру символів).

Повертає:

  • Список частин, на які розбито рядок.

Приклад:

>>> import re
>>>
>>> string = "apple, banana, cherry"
>>> pattern = r',\s*'
>>> parts = re.split(pattern, string)
>>> parts
['apple', 'banana', 'cherry']
>>>
  • рядок "apple, banana, cherry" розбито на три частини за допомогою регулярного виразу ,\s*.
  • Регулярний вираз ,\s* відповідає комі та будь-якій кількості пробілів після неї.

Ще приклад:

>>> string = "apple1 banana2 cherry3"
>>> parts = re.split(r'\d', string)
>>> parts
['apple', ' banana', ' cherry', '']
>>>
  • рядок "apple1 banana2 cherry3" розбито на чотири частини за допомогою регулярного виразу \d.
  • Регулярний вираз \d відповідає будь-якій цифрі.
  • Остання частина є порожнім рядком, оскільки рядок закінчується цифрою.

Ще один приклад:

>>> string = "apple1 banana2 cherry3"
>>> parts = re.split(r'\d', string, maxsplit=1)
>>> parts
['apple', ' banana2 cherry3']
>>>
  • рядок "apple1 banana2 cherry3" розбито на дві частини за допомогою регулярного виразу \d.
  • Максимальна кількість розбиттів встановлена рівною 1.

re.findall()

Пошук усіх відповідностей регулярного виразу в рядку.

re.findall(pattern, string, flags=0)

Параметри:

  • pattern — регулярний вираз.
  • string — рядок, в якому виконується пошук.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку (наприклад, для ігнорування регістру символів).

Повертає:

  • Список усіх відповідностей, якщо вони знайдені.
  • Порожній список, якщо відповідностей не знайдено.

Кожен елемент списку містить рядок, який відповідає регулярному виразу. Якщо в регулярному виразі є групи, то кожен елемент списку буде кортежем, що містить відповідні групи.

Приклад:

>>> import re
>>>
>>> string = "Hello, world! Hello, Python!"
>>> pattern = r"Hello, (\w+)!"
>>> matches = re.findall(pattern, string)
>>> matches
['world', 'Python']
>>>
  • знайдено дві відповідності "Hello, world!" та "Hello, Python!" в рядку "Hello, world! Hello, Python!".
  • перша група в регулярному виразі відповідає рядку "world" в першій відповідності та "Python" в другій.

Ще приклад:

>>> string = "Hello, world! Hello, Python!"
>>> matches = re.findall(r'\w+', string)
>>> matches
['Hello', 'world', 'Hello', 'Python']
>>>
  • знайдено всі слова в рядку "Hello, world! Hello, Python!".
  • кожен елемент списку містить одне слово, яке відповідає регулярному виразу \w+.

re.finditer()

Пошук усіх відповідностей регулярного виразу в рядку з поверненням ітератора об'єктів Match.

re.finditer(pattern, string, flags=0)

Параметри:

  • pattern — регулярний вираз.
  • string — рядок, в якому виконується пошук.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку (наприклад, для ігнорування регістру символів).

Повертає:

  • Ітератор об'єктів Match, якщо знайдено відповідності.
  • Порожній ітератор, якщо відповідностей не знайдено.

Приклад:

>>> import re
>>>
>>> string = "Hello, world! Hello, Python!"
>>> pattern = r"Hello, (\w+)!"
>>> matches = re.finditer(pattern, string)
>>> for match in matches:
...     print(match.group())
...
Hello, world!
Hello, Python!
>>>
  • знайдено дві відповідності "Hello, world!" та "Hello, Python!" в рядку "Hello, world! Hello, Python!".
  • перша група в регулярному виразі відповідає рядку "world" в першій відповідності та "Python" в другій.

Ще приклад:

>>> string = "Hello, world! Hello, Python!"
>>> matches = re.finditer(r'\w+', string)
>>> for match in matches:
...     print(match.group())
...
Hello
world
Hello
Python
>>>
  • знайдено всі слова в рядку "Hello, world! Hello, Python!".
  • кожен об'єкт Match містить одне слово, яке відповідає регулярному виразу \w+.

re.sub()

Заміна всіх відповідностей регулярного виразу в рядку на заданий рядок.

re.sub(pattern, repl, string, count=0, flags=0)

Параметри:

  • pattern — регулярний вираз.
  • repl — рядок, на який будуть замінені відповідності.
  • string — рядок, в якому виконується пошук та заміна.
  • count — необов'язковий параметр, який вказує максимальну кількість замін. За замовчуванням, виконується заміна всіх відповідностей.
  • flags — необов'язковий параметр, який може бути використаний для встановлення додаткових опцій пошуку (наприклад, для ігнорування регістру символів).

Повертає:

  • Новий рядок, в якому виконана заміна.

Приклад:

>>> import re
>>>
>>> string = "Hello, world! Hello, Python!"
>>> pattern = r"Hello, (\w+)!"
>>> new_string = re.sub(pattern, r"Hi, \1!", string)
>>> new_string
'Hi, world! Hi, Python!'
>>>
  • в рядку "Hello, world! Hello, Python!" знайдено дві відповідності "Hello, world!" та "Hello, Python!".
  • перша група в регулярному виразі відповідає рядку "world" в першій відповідності та "Python" в другій.
  • за допомогою \1 в рядку заміни r"Hi, \1!" посилається на першу групу регулярного виразу.

Ще приклад:

>>> string = "apple1 banana2 cherry3"
>>> new_string = re.sub(r'\d', '', string)
>>> new_string
'apple banana cherry'
>>>
  • в рядку "apple1 banana2 cherry3" знайдено три відповідності "1", "2" та "3".
  • кожна відповідність замінюється на порожній рядок.

Ще один приклад:

>>> string = "apple1 banana2 cherry3"
>>> new_string = re.sub(r'\d', '', string, count=1)
>>> new_string
'apple banana2 cherry3'
>>>
  • в рядку "apple1 banana2 cherry3" знайдено три відповідності "1", "2" та "3".
  • виконується заміна лише першої відповідності "1" на порожній рядок.

re.compile()

Ккомпілює регулярний вираз в об'єкт Pattern. Цей об'єкт можна використовувати для пошуку відповідностей в рядках за допомогою методів match(), search(), findall(), finditer(), sub(), subn(), split().

`re.compile(pattern, flags=0)`

Параметри:

  • pattern - регулярний вираз, який потрібно скомпілювати.
  • flags - необов'язковий параметр, який вказує додаткові опції компіляції регулярного виразу.

Приклад:

import re

# Компіляція регулярного виразу
pattern = re.compile(r'\d+')

# Пошук всіх відповідностей в рядку
string = '123 456 789'
matches = pattern.findall(string)
print(matches)  # ['123', '456', '789']

# Заміна всіх відповідностей в рядку
new_string = pattern.sub('X', string)
print(new_string)  # 'X X X'

Компіляція регулярного виразу в об'єкт Pattern дозволяє зберегти час на компіляцію, якщо регулярний вираз використовується багато разів. Також, завдяки компіляції, можна зберігати регулярні вирази в змінних та передавати їх як аргументи в функції.

flags

flags — необов'язковий параметр, який може бути переданий в функції модуля re для встановлення додаткових опцій пошуку регулярних виразів:

  • re.ASCII або re.A - встановлює режим ASCII. Змінює поведінку символьних класів, таких як \w, \s, \d, які відповідають лише символам ASCII.
  • re.IGNORECASE або re.I - ігнорування регістру символів.
  • re.DOTALL або re.S - дозволяє точці . відповідати символу нового рядка \n.
  • re.MULTILINE або re.M - багаторядковий режим. Змінює поведінку символів ^ та $, які відповідають початку та кінцю рядка, відповідно. У багаторядковому режимі вони відповідають початку та кінцю кожного рядка.

Приклад використання flags:

>>> import re
>>>
>>> string = "Hello, World!"
>>> pattern = r"hello"
>>> match = re.search(pattern, string, flags=re.IGNORECASE)
>>> match.group()
'Hello'
>>>
  • в рядку "Hello, World!" знайдено відповідність "Hello" за допомогою регулярного виразу hello з встановленим прапором re.IGNORECASE.

Прапорці можуть бути комбіновані за допомогою оператора |. Наприклад, re.IGNORECASE | re.DOTALL.

Плюси та мінуси регулярних виразів

Переваги використання регулярних виразів:

  1. Гнучкість: регулярні вирази дозволяють знаходити відповідності в рядках на основі шаблонів, а не точних збігів. Це дозволяє шукати складніші закономірності в тексті.
  2. Ефективність: регулярні вирази часто працюють швидше, ніж інші методи пошуку рядків, оскільки вони оптимізовані для роботи з текстом.
  3. Використання в багатьох мовах програмування: регулярні вирази підтримуються в багатьох мовах програмування, що робить їх універсальним інструментом для роботи з текстом.
  4. Можливість заміни та видобування даних: регулярні вирази дозволяють не лише шукати відповідності, але й замінювати їх на інший текст або видобувати дані з відповідностей.

Недоліки регулярних виразів:

  1. Складність: регулярні вирази можуть бути складними в розумінні та написанні.
  2. Погана читабельність: складні регулярні вирази можуть бути важкими для розуміння іншими людьми, що ускладнює обслуговування коду.
  3. Повільна робота з великими обсягами даних: регулярні вирази можуть працювати повільно з великими обсягами даних, особливо якщо шаблон складний.

Загалом регулярні вирази є потужним інструментом для роботи з текстом, але вони вимагають обережності та розуміння їх можливостей та обмежень.
