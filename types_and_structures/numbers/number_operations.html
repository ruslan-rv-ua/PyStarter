Числа в Python

Python підтримує різні типи чисел, включаючи цілі числа (int), числа з плаваючою комою (float) та комплексні числа (complex). Розглянемо основні операції та функції, які можна виконувати з цими типами.

Операції з числами

Python підтримує стандартні арифметичні операції:

Оператор Значення Пояснення
+ додавання
- віднімання
* множення При множенні чисел з плаваючою комою іноді можуть виникати невеликі похибки через особливості їх двійкового представлення. Для точних фінансових розрахунків краще використовувати модуль decimal.
/ ділення Результат завжди буде числом з плаваючою комою, навіть якщо обидва операнди цілі.
// цілочисельне ділення Результат буде цілим числом, якщо обидва операнди цілі. Якщо хоча б один з операндів є числом з плаваючою комою, результат буде числом з плаваючою комою.
% залишок від ділення Знак результату операції % такий самий, як знак дільника (другого операнда). Це може відрізнятися від поведінки в деяких інших мовах програмування.
** піднесення до степеня Аналогічно функції pow().
- унарний мінус Змінює знак числа.
+ унарний плюс Не змінює знак числа, але може бути використаний для явного позначення додатного числа.

У Python цілочисельне ділення (//) та оператор модуля (%) нерозривно пов'язані і підкоряються чітким правилам, особливо щодо від'ємних чисел. Розуміння цієї взаємодії є ключовим.

Особливості цілочисельного ділення (//)

  1. Завжди ціле число: Оператор // завжди повертає ціле число. Він виконує "ділення з округленням до меншого" (floor division). Це означає, що результат округлюється до найближчого цілого числа, яке менше або дорівнює точному результату ділення.

  2. Поведінка з від'ємними числами: Це найважливіша відмінність. На відміну від деяких інших мов, Python округлює до від'ємної нескінченності.

    • 10 // 3 дає 3 (3.33 округлюється до 3).
    • -10 // 3 дає -4 (бо -3.33 округлюється до -4, оскільки -4 менше -3.33).
    • 10 // -3 дає -4 (бо -3.33 округлюється до -4).
    • -10 // -3 дає 3 (бо 3.33 округлюється до 3).

  3. Тип результату: Якщо обидва операнди є цілими числами (int), результат також буде int. Якщо хоча б один є числом з плаваючою точкою (float), результат буде float (наприклад, 3.0).

Особливості оператора модуля (%)

  1. Визначення залишку: Оператор % повертає залишок від ділення.

  2. Знак залишку: У Python знак залишку завжди збігається зі знаком дільника. Це прямий наслідок поведінки // при округленні до від'ємної нескінченності.

    • 10 % 3 дає 1 (10 = 3 * 3 + 1).
    • -10 % 3 дає 2 (бо -10 = -4 * 3 + 2; дільник 3 позитивний, залишок 2 позитивний).
    • 10 % -3 дає -2 (бо 10 = -4 * -3 - 2; дільник -3 негативний, залишок -2 негативний).
    • -10 % -3 дає -1 (бо -10 = 3 * -3 - 1; дільник -3 негативний, залишок -1 негативний).

Взаємозв'язок // та %

В Python завжди виконується таке фундаментальне співвідношення:

a = (a // b) * b + (a % b)

Де:

  • a — ділене
  • b — дільник
  • a // b — результат цілочисельного ділення
  • a % b — залишок від ділення

Ця властивість є ключовою для розуміння, чому Python обробляє // і % саме так. Завдяки округленню // до від'ємної нескінченності, оператор % може гарантувати, що знак залишку завжди відповідає знаку дільника. Це робить поведінку оператора модуля більш передбачуваною та корисною в багатьох алгоритмах, де важливий знак залишку.

Наприклад:

  • a = 10, b = 3: (10 // 3) * 3 + (10 % 3) = 3 * 3 + 1 = 9 + 1 = 10
  • a = -10, b = 3: (-10 // 3) * 3 + (-10 % 3) = (-4) * 3 + 2 = -12 + 2 = -10

Порівняння зі звичайним діленням (/)

На відміну від //, оператор / (звичайне ділення) завжди виконує "справжнє" ділення і повертає число з плаваючою точкою (float), незалежно від типів операндів.

  • 10 / 3 дає 3.3333333333333335
  • 10 // 3 дає 3

Розуміння цих нюансів є критично важливим для коректного програмування в Python, особливо при роботі з від'ємними числами та математичними операціями, де точність округлення та залишку має значення.

Функції для роботи з числами

Python надає багато вбудованих функцій для роботи з числами.

abs(x)

Повертає абсолютне значення (модуль) числа x.

>>> abs(-5)
5
>>> abs(5)
5
>>> abs(-3.14)
3.14

round(number[, ndigits])

Округлює число number до ndigits знаків після коми. Якщо ndigits не вказано, округлює до найближчого цілого.

>>> round(3.14159)
3
>>> round(3.14159, 2)
3.14
>>> round(2.5) # Округлення до найближчого парного числа для .5
2
>>> round(3.5)
4
>>> round(2.675, 2) # Також може бути неочікуваним через представлення чисел з плаваючою комою
2.67
Особливості функції round():

  1. Округлення до найближчого парного (Round half to even): Починаючи з Python 3, для чисел, що знаходяться точно посередині між двома можливими округленими значеннями (наприклад, 2.5, 3.5, або 2.675 при округленні до двох знаків), round() використовує стратегію "округлення до найближчого парного числа".

    • round(2.5) повертає 2 (бо 2 парне).
    • round(3.5) повертає 4 (бо 4 парне). Цей метод допомагає зменшити статистичне зміщення, яке могло б виникнути при послідовному округленні в один бік (наприклад, завжди вгору).

  2. Проблеми з точністю чисел з плаваючою комою: Десяткові дроби часто не можуть бути точно представлені у двійковому форматі з плаваючою комою, який використовується комп'ютерами. Це може призводити до неочікуваних результатів округлення. Наприклад, round(2.675, 2) може повернути 2.67. Це відбувається тому, що десяткове число 2.675 може зберігатися у пам'яті як двійкове число, що є трохи меншим, наприклад, 2.6749999999999998. При округленні такого внутрішнього представлення до двох знаків результатом буде 2.67. Якщо потрібна висока точність для десяткових арифметичних операцій, варто розглянути використання модуля decimal.

divmod(a, b)

Повертає пару чисел (a // b, a % b), тобто частку та остачу від ділення a на b.

Для цілих чисел результат еквівалентний (a // b, a % b). Для чисел з плаваючою комою результат еквівалентний (math.floor(a / b), a % b).

>>> divmod(7, 3)
(2, 1)
>>> divmod(8, 2)
(4, 0)
>>> divmod(10.5, 3)
(3.0, 1.5)
>>> import math
>>> math.floor(10.5 / 3)
3.0
>>> 10.5 % 3
1.5

pow(base, exp[, mod])

Повертає base у степені exp. Якщо вказано mod, повертає (base ** exp) % mod.

>>> pow(2, 3)
8
>>> pow(3, 2)
9
>>> pow(2, 3, 5)  # (2**3) % 5 = 8 % 5
3

Спеціальні методи

Багато операцій та вбудованих функцій, що працюють з числами, насправді викликають спеціальні методи об'єктів. Розуміння цих методів корисне для створення власних числових типів або для глибшого розуміння поведінки Python.

Метод Оператор/Функція Опис
__add__(self, other) + Додавання (self + other)
__sub__(self, other) - Віднімання (self - other)
__mul__(self, other) * Множення (self * other)
__truediv__(self, other) / Справжнє ділення (self / other)
__floordiv__(self, other) // Цілочисельне ділення (self // other)
__mod__(self, other) % Залишок від ділення (self % other)
__divmod__(self, other) divmod() Повертає пару (self // other, self % other)
__pow__(self, other[, modulo]) **, pow() Піднесення до степеня (self ** other або pow(self, other, modulo))
__radd__(self, other) + Правостороннє додавання (other + self), викликається, якщо other не підтримує __add__
__rsub__(self, other) - Правостороннє віднімання (other - self)
__rmul__(self, other) * Правостороннє множення (other * self)
__rtruediv__(self, other) / Правостороннє справжнє ділення (other / self)
__rfloordiv__(self, other) // Правостороннє цілочисельне ділення (other // self)
__rmod__(self, other) % Правосторонній залишок від ділення (other % self)
__rdivmod__(self, other) divmod() Правосторонній divmod(other, self)
__rpow__(self, other[, modulo]) **, pow() Правостороннє піднесення до степеня (other ** self)
__neg__(self) - (унарний) Унарний мінус (-self)
__pos__(self) + (унарний) Унарний плюс (+self)
__abs__(self) abs() Абсолютне значення (abs(self))
__int__(self) int() Перетворення на ціле число (int(self))
__float__(self) float() Перетворення на число з плаваючою комою (float(self))
__round__(self[, ndigits]) round() Округлення (round(self, ndigits))
__complex__(self) complex() Перетворення на комплексне число (complex(self))
__index__(self) Використовується при зрізах, перетворює об'єкт на цілочисельний індекс. Наприклад, operator.index().

Ці методи дозволяють об'єктам вашого класу поводитися як вбудовані числові типи при використанні стандартних операторів та функцій.

Наприклад, розглянемо, як працює __add__:

class MyNumber:
    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        if isinstance(other, MyNumber):
            return MyNumber(self.value + other.value)
        elif isinstance(other, (int, float)):
            return MyNumber(self.value + other)
        else:
            return NotImplemented # Важливо для правильної роботи правосторонніх операцій

    def __radd__(self, other):
        # Цей метод викликається, якщо MyNumber стоїть праворуч від оператора +,
        # а лівий операнд не знає, як додати MyNumber.
        # Наприклад: 5 + num1 (де num1 - екземпляр MyNumber)
        if isinstance(other, (int, float)):
            return MyNumber(other + self.value)
        else:
            return NotImplemented

    def __str__(self):
        return f"MyNumber({self.value})"

num1 = MyNumber(10)
num2 = MyNumber(20)

result1 = num1 + num2  # Викликає num1.__add__(num2)
print(result1)         # Виведе: MyNumber(30)

result2 = num1 + 5     # Викликає num1.__add__(5)
print(result2)         # Виведе: MyNumber(15)

result3 = 15 + num1    # Викликає num1.__radd__(15), оскільки int не має __add__ для MyNumber
print(result3)         # Виведе: MyNumber(25)

# Якщо __radd__ не визначено, і лівий операнд не може виконати додавання,
# виникне TypeError.
# Якщо __add__ повертає NotImplemented, Python спробує викликати __radd__ на правому операнді.
