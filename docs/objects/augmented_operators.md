# Операції з присвоєнням

> Розширені оператори (augmented operators) — 
оператори, які поєднують в собі виконання певної операції та присвоєння результату цій же змінній.

Розглянемо, як працюють оператори `+=` та `*=` з мутабельними типами даних, такими як списки.

## Конкатенація з присвоєнням

Створимо дві змінні які посилаються на один і той же список:

```python
>>> a = [1, 2]
>>> b = a
```

Тепер додамо до списку `a` ще декілька елементів:

```python
>>> a = a + [3, 4]
>>> a
[1, 2, 3, 4]
>>> b
[1, 2]
>>>
```

Як бачимо, список `b` не змінився. 
Це тому, що оператор `+` (конкатенація списків) створює новий список, а не змінює старий. 

Тепер спробуємо зробити те ж саме, але з використанням оператора `+=`:

```python
>>> a = [1, 2]
>>> b = a
>>> a += [3, 4]
>>> a
[1, 2, 3, 4]
>>> b
[1, 2, 3, 4]
>>> a is b
True
```

Оператор `+=` для списків реалізований так, щоб модифікувати існуючий список без створення нового. 
Він додає елементи з правого операнда до списку, на який посилається лівий операнд. 
Оскільки і `a`, і `b` посилалися на той самий об'єкт списку в пам'яті, 
а операція `+=` змінила цей об'єкт на місці, 
то зміни видно через обидві змінні (`a` та `b`). 
Ідентифікатор об'єкта (`id(a)`) залишається незмінним, і `a is b` продовжує повертати `True`. 

Вибір між `+` та `+=` залежить від того, чи хочете ви зберегти оригінальний список незмінним, чи модифікувати його безпосередньо. 
Будьте особливо уважні при роботі з мутабельними типами, коли декілька змінних можуть посилатися на один і той самий об'єкт.

Для немутабельних типів операція `+=` завжди створює новий об'єкт, 
оскільки існуючий об'єкт змінити не можна.

```python
>>> t1 = (1, 2)
>>> t2 = t1
>>> t1 += (3, 4)
>>> t1
(1, 2, 3, 4)
>>> t2
(1, 2)
>>> t1 is t2
False
```

## Реплікація з присвоєнням

Подібно до оператора `+=`, у Python також існує оператор `*=` для множення з присвоєнням. Розглянемо, як він працює з різними типами даних:

Спочатку створимо дві змінні, які посилаються на той самий список:

```python
>>> a = [1, 2]
>>> b = a
```

Тепер спробуємо застосувати звичайний оператор множення `*`:

```python
>>> a = a * 3
>>> a
[1, 2, 1, 2, 1, 2]
>>> b
[1, 2]
>>> a is b
False
```

Як і у випадку з оператором `+`, оператор `*` створює новий список, а не змінює існуючий. Тому `b` залишається незмінним.

Тепер розглянемо, як працює оператор `*=`:

```python
>>> a = [1, 2]
>>> b = a
>>> a *= 3
>>> a
[1, 2, 1, 2, 1, 2]
>>> b
[1, 2, 1, 2, 1, 2]
>>> a is b
True
```

Оператор `*=` для мутабельних послідовностей (таких як список) модифікує існуючий об'єкт, не створюючи новий. Він повторює елементи списку вказану кількість разів в межах того ж об'єкта. Оскільки і `a`, і `b` посилалися на один і той же об'єкт, обидві змінні відображають зміни.

Для немутабельних типів, таких як кортежі, оператор `*=` працює аналогічно оператору `+=` — створюється новий об'єкт:

```python
>>> t1 = (1, 2)
>>> t2 = t1
>>> t1 *= 3
>>> t1
(1, 2, 1, 2, 1, 2)
>>> t2
(1, 2)
>>> t1 is t2
False
```
