• BaseException - Базовий клас для всіх вбудованих винятків.
    • SystemExit - Виникає при виклику функції sys.exit().
    • KeyboardInterrupt - Виникає, коли користувач натискає клавішу переривання (Ctrl+C або Delete).
    • GeneratorExit - Виникає, коли генератор або співпрограма закривається.
    • Exception - Базовий клас для всіх несистемних винятків.
      • StopIteration - Виникає, коли ітератор не має більше значень.
      • StopAsyncIteration - Виникає, коли асинхронний ітератор не має більше значень.
      • ArithmeticError - Базовий клас для арифметичних помилок.
        • FloatingPointError - Виникає при помилці операції з плаваючою комою.
        • OverflowError - Виникає, коли результат арифметичної операції занадто великий для представлення.
        • ZeroDivisionError - Виникає при діленні на нуль.
      • AssertionError - Виникає, коли інструкція assert не виконується.
      • AttributeError - Виникає при невдалому доступі до атрибута або його присвоєнні.
      • BufferError - Виникає, коли операція, пов'язана з буфером, не може бути виконана.
      • EOFError - Виникає, коли функція input() досягає кінця файлу без зчитування даних.
      • ImportError - Виникає, коли інструкція import не може знайти модуль або ім'я.
        • ModuleNotFoundError - Підклас ImportError; виникає, коли модуль не знайдено.
      • LookupError - Базовий клас для помилок пошуку.
        • IndexError - Виникає, коли індекс послідовності виходить за межі діапазону.
        • KeyError - Виникає, коли ключ словника не знайдено.
      • MemoryError - Виникає, коли операція вичерпує пам'ять.
      • NameError - Виникає, коли локальне або глобальне ім'я не знайдено.
        • UnboundLocalError - Виникає при посиланні на локальну змінну, якій не присвоєно значення.
      • OSError - Базовий клас для помилок, пов'язаних з операційною системою.
        • BlockingIOError - Виникає, коли операція блокувала б об'єкт, налаштований на неблокуючий режим.
        • ChildProcessError - Виникає при помилці в дочірньому процесі.
        • ConnectionError - Базовий клас для помилок, пов'язаних зі з'єднанням.
          • BrokenPipeError - Виникає при спробі запису в канал, коли інший кінець закрито...
          • ConnectionAbortedError - Виникає, коли спроба з'єднання була перервана іншою стороною.
          • ConnectionRefusedError - Виникає, коли спроба з'єднання була відхилена іншою стороною.
          • ConnectionResetError - Виникає, коли з'єднання було розірвано іншою стороною.
        • FileExistsError - Виникає при спробі створити файл або каталог, який вже існує.
        • FileNotFoundError - Виникає, коли файл або каталог не знайдено.
        • InterruptedError - Виникає, коли системний виклик переривається вхідним сигналом.
        • IsADirectoryError - Виникає, коли операція з файлом застосовується до каталогу.
        • NotADirectoryError - Виникає, коли операція, що очікує каталог, застосовується до чогось іншого.
        • PermissionError - Виникає при спробі виконати операцію без належних прав доступу.
        • ProcessLookupError - Виникає, коли заданий процес не існує.
        • TimeoutError - Виникає, коли системна функція вичерпує час очікування.
      • ReferenceError - Виникає при спробі доступу до атрибута слабкого посилання, яке вже було зібрано.
      • RuntimeError - Виникає, коли виявлено помилку, яка не належить до жодної з інших категорій.
        • NotImplementedError - Виникає, коли абстрактні методи вимагають реалізації.
        • RecursionError - Виникає, коли перевищено максимальну глибину рекурсії.
      • SyntaxError - Виникає, коли парсер зустрічає синтаксичну помилку.
        • IndentationError - Виникає при неправильному відступі.
          • TabError - Виникає, коли відступи містять суперечливе використання табуляції та пробілів.
      • SystemError - Виникає, коли інтерпретатор знаходить внутрішню помилку.
      • TypeError - Виникає, коли операція або функція застосовується до об'єкта невідповідного типу.
      • ValueError - Виникає, коли операція або функція отримує аргумент правильного типу, але з неприпустимим значенням.
        • UnicodeError - Базовий клас для помилок, пов'язаних з кодуванням/декодуванням Unicode.
          • UnicodeDecodeError - Виникає при помилці декодування Unicode.
          • UnicodeEncodeError - Виникає при помилці кодування Unicode.
          • UnicodeTranslateError - Виникає при помилці трансляції Unicode.
      • Warning - Базовий клас для попереджень.
        • DeprecationWarning - Попередження про застарілі функції.
        • PendingDeprecationWarning - Попередження про функції, які будуть застарілими в майбутньому.
        • RuntimeWarning - Попередження про сумнівну поведінку під час виконання.
        • SyntaxWarning - Попередження про сумнівний синтаксис.
        • UserWarning - Попередження, генеровані кодом користувача.
        • FutureWarning - Попередження про функції, які будуть змінені в майбутньому.
        • ImportWarning - Попередження, що виникають під час імпорту модулів.
        • UnicodeWarning - Попередження, пов'язані з Unicode.
        • BytesWarning - Попередження, пов'язані з байтами та байтовими рядками.
        • ResourceWarning - Попередження, пов'язані з використанням ресурсів.
