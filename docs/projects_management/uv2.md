# uv: універсальне рішення для проєктів Python

uv – це сучасний високошвидкісний інструмент для керування пакунками та проєктами Python, розроблений на Rust. Його головна перевага – надзвичайна швидкість, що може бути у 10-100 разів вищою за стандартний pip. Давайте розглянемо, як uv може оптимізувати ваш робочий процес та стати універсальним рішенням для ваших Python проєктів.

## Що таке uv?

uv об'єднує функціональність кількох популярних інструментів екосистеми Python:

- pip і pip-tools (керування пакунками)
- virtualenv (керування віртуальними середовищами)
- pyenv (керування версіями Python)
- poetry (керування проєктами)
- twine (публікація пакунків)

Це єдиний самостійний бінарний файл, що значно спрощує встановлення та використання.

## Встановлення uv

Існує кілька способів встановлення uv. Розглянемо найпопулярніші:

### 1. Використання самостійного інсталятора

Для Linux та macOS:

```shell
>>> curl -LsSf https://astral.sh/uv/install.sh | sh
# uv успішно встановлено!
```

Або, використовуючи wget:

```shell
>>> wget -qO- https://astral.sh/uv/install.sh | sh
# uv успішно встановлено!
```

Для встановлення конкретної версії:

```shell
>>> curl -LsSf https://astral.sh/uv/0.6.12/install.sh | sh
# uv 0.6.12 успішно встановлено!
```

### 2. Встановлення з PyPI

Використовуючи pipx для глобального доступу:

```shell
>>> pipx install uv
# uv успішно встановлено!
```

### Перевірка встановлення

Після встановлення перевірте версію:

```shell
>>> uv --version
uv 0.6.12
```

## Керування проєктами Python

### Створення нового проєкту

Для створення та ініціалізації проєкту виконайте:

```shell
>>> uv init rpcats
# Створено проєкт rpcats з наступною структурою:
# rpcats/
# ├── .git/
# ├── .gitignore
# ├── .python-version
# ├── README.md
# ├── main.py
# └── pyproject.toml
```

Команда `uv init` автоматично створює:
- Git репозиторій
- .gitignore з типовими виключеннями
- .python-version для вказання версії Python
- Порожній README.md
- main.py з базовим кодом
- pyproject.toml з базовою конфігурацією

### Запуск скрипта проєкту

Після створення проєкту запустити головний скрипт можна так:

```shell
>>> uv run main.py
# Створення віртуального середовища у .venv/
# Використовується Python 3.11.7
# Hello, World!
```

При першому запуску uv автоматично:
1. Створює віртуальне середовище у `.venv/`
2. Створює файл `uv.lock` для блокування залежностей

## Керування залежностями

### Додавання залежностей

Щоб додати нову залежність до проєкту:

```shell
>>> uv add requests
# Додано requests 2.31.0 до pyproject.toml
# Оновлено uv.lock
# Встановлено requests 2.31.0 та його залежності
```

Для додавання залежностей розробки використовуйте опцію `--dev`:

```shell
>>> uv add --dev pytest
# Додано pytest 7.4.3 до pyproject.toml у секцію [dependency-groups.dev]
# Оновлено uv.lock
# Встановлено pytest 7.4.3 та його залежності
```

### Оновлення залежностей

Для оновлення існуючої залежності:

```shell
>>> uv add --upgrade requests
# Оновлено requests до версії 2.32.0
# Оновлено uv.lock
```

### Видалення залежностей

Щоб видалити залежність з проєкту:

```shell
>>> uv remove requests
# Видалено requests та його транзитивні залежності
# Оновлено pyproject.toml та uv.lock
```

## Блокування та синхронізація середовища

Файл `uv.lock` містить точну інформацію про всі залежності проєкту. Він забезпечує відтворюваність середовища на будь-якій системі.

### Перегляд встановлених пакунків

```shell
>>> uv pip list
# Package      Version
# ------------ -------
# requests     2.31.0
# certifi      2023.7.22
# charset-normalizer 3.3.0
# idna         3.4
# urllib3      2.0.6
```

### Явне блокування та синхронізація

При необхідності ви можете явно виконати блокування та синхронізацію:

```shell
>>> uv lock
# Оновлено uv.lock
>>> uv sync
# Синхронізовано залежності з uv.lock
```

## Збірка та публікація пакунків

### Конфігурація проєкту для збірки

У файлі `pyproject.toml` потрібно налаштувати:

1. Точку входу для CLI додатків:

```toml
[project.scripts]
rpcats = "main:main"
```

2. Систему збірки:

```toml
[build-system]
requires = ["setuptools>=42", "wheel>=0.37.0"]
build-backend = "setuptools.build_meta"
```

### Збірка дистрибутиву

```shell
>>> uv build
# Створено dist/rpcats-0.1.0.tar.gz (sdist)
# Створено dist/rpcats-0.1.0-py3-none-any.whl (wheel)
```

### Публікація дистрибутиву

Для публікації на TestPyPI:

```shell
>>> uv publish --index testpypi --token your_token_here
# Опубліковано rpcats-0.1.0 на TestPyPI
```

Для публікації на основний PyPI:

```shell
>>> uv publish --token your_token_here
# Опубліковано rpcats-0.1.0 на PyPI
```

## Висновок

uv – це потужний та швидкий інструмент, що спрощує керування проєктами Python. Його основні переваги:

1. Надзвичайна швидкість (до 100 разів швидше за pip)
2. Єдиний інструмент замість багатьох окремих
3. Автоматичне керування віртуальними середовищами
4. Відтворюване середовище через файл блокування

Це робить uv відмінним вибором для будь-яких Python проєктів, від невеликих скриптів до складних програмних систем.
