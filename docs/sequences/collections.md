# Колекції в Python

> **Колекція** — це структура даних, яка зберігає кілька елементів разом у певному порядку або відповідно до певних правил. Колекції дозволяють зберігати, змінювати та обробляти дані ефективним способом.

До основних вбудованих колекцій у Python належать:

- Список (list): Впорядкована, змінна послідовність елементів.
- Кортеж (tuple): Впорядкована, незмінна послідовність елементів.
- Множина (set): Невпорядкована колекція унікальних елементів.
- Словник (dict): Невпорядкована колекція пар ключ-значення.

У цьому розділі ми розглянемо списки та кортежі. Множини та словники будуть розглянуті у наступних розділах.
