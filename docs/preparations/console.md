# Інтерактивний режим інтерпретатора Python

**Замість епіграфу.**
*Чому програміст не зміг скористатись ліфтом? Вивчивши клавіатуру не знайшов Enter*

-----

## Поговоримо?

Після запуску інтерпретатора Python він працює у інтерактивному режимі, тобто користувач вводить команду, інтерпретатор виконує її і одразу видає результат.

```
Python 3.12.9 (tags/v3.12.9:fdb8142, Feb  4 2025, 15:27:58) [MSC v.1942 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
```
		
Три знаки "більше" — це запрошення інтерпретатора ввести якусь команду. Після вводу команди необхідно натиснути клавішу **Enter**. І одразу у терміналі з'явиться результат виконання введеної команди.

На даний момент ми не знаємо жодної команди Python. Але прямо зараз ми можемо використовувати Python як калькулятор.

```
>>> 2+2
4
>>> (10-3)*2
14
>>>
```	

У вищенаведеному прикладі знак зірочки `*` означає множення чисел.

## Історія команд

Термінал має "пам'ять", тобто він запам'ятовує певну кількість введених користувачем команд. Такий функціонал зазвичай називають "історія команд". Пересуватись по історії команд (переглядати введені раніше команди) можна за допомогою клавіатури.
Щоб "гортати" історію команд використовуйте клавіші зі стрілками вверх і вниз.

Історію команд зручно використовувати щоб не вводити команди з самого початку у разі якщо Ви припустились помилки або якщо Ви хочете виконати попередньо введену команду

## Кому це потрібно?

Інтерактивний режим Python зручно використовувати

- власне як калькулятор, а при певних знаннях як дуже "просунутий" калькулятор
- у процесі навчання
- для тестування невеликих за об'ємом фрагментів коду
- перегляду вбудованої довідки

Інтерактивним режимом користуються не тільки початківці, але вже деколи і досвідчені розробники програмного забезпечення.
