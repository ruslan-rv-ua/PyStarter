# Інтерпретатор Python

В рамках даного курсу ми будемо використовувати інтерпретатор Python з номером версії **3.12**.

## Крок за кроком: встановлення і запуск інтерпретатора Python

1. Завантажте інсталятор Python для 32-бітної або 64-бітної версії Windows з [офіційного сайта](https://www.python.org/downloads/).
1. Запустіть завантажений файл
1. У відкрившомуся діалолговому вікні:
	- позначьте прапорець "Add python.exe to PATH"
	- активуйте кнопку "Customize Installation"
1. У відкрившомуся діалолговому вікні переконайтесь що позначені наступні прапорці:
	- Documentation
	- pip
	- py launcher
1. Решту прапорців залишіть без змін і активуйте кнопку "Next".
1. У відкрившомуся діалолговому вікні переконайтесь що позначені наступні прапорці:
	- Install Python 3.12 for all users
	- Associate files with Python (requires the 'py' launcher)
	- Create shortcuts for installed applications
	- Add Python to environment variables
1. **ВАЖЛИВО!** У полі редагування "Customize install location" вкажіть папку у корені Вашого системного диску з наступною назвою:
	```
	Python312
	```
	Наприклад: "C:\Python312".
1. Активуйте кнопку "Install". Почнеться процес інсталяції.
1. Після завершення процесу інсталяції у діалоговому вікні натисніть кнопку "Close"

## Запуск інтерпретатора

Запустити інтерпретатор Python можна одним з наступних способів:

- ввівши у терміналі команду:
	
	```
	python
	```

- натиснувши гарячі клавіші **Win + R** відкрити діалог Windows "Виконати" і ввести у ньому команду:
	```
	python
	```

- знайшовши Python у основному меню Windows
- запустивши наступний файл:
	```
	c:\Python312\python.exe
	```

Після запуска у вікні термінала з'явиться інформація про номер версії Python та інша системна інформація:

```
Python 3.12.9 (tags/v3.12.9:fdb8142, Feb  4 2025, 15:27:58) [MSC v.1942 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

Завершити роботу інтерпретатора можна натиснувши гарячі клавіші **Ctrl + Z** та натиснувши Enter

	```

	```

	```
    python -m http.server 8007
	```
