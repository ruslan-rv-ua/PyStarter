# Оператор об'єднання словників

Оператор `|` для словників з'явився у Python 3.9 і дозволяє об'єднувати словники.
Він створює новий словник, що містить пари "ключ-значення" з обох операндів.
Якщо ключ присутній в обох словниках, використовується значення з правого операнда.

	>>> d1 = {'a': 1, 'b': 2}
	>>> d2 = {'b': 3, 'c': 4}
	>>> d1 | d2
	{'a': 1, 'b': 3, 'c': 4}
	>>>

Зверніть увагу, що ключ 'b' присутній в обох словниках, але у результаті використовується значення 3 з другого словника (d2).

Оператор не змінює операнди, а створює новий словник:

	>>> d1 = {'name': 'Сидоренко', 'age': 21}
	>>> d2 = {'age': 30, 'phone': '+380971234567'}
	>>> result = d1 | d2
	>>> result
	{'name': 'Сидоренко', 'age': 30, 'phone': '+380971234567'}
	>>> d1
	{'name': 'Сидоренко', 'age': 21}
	>>> d2
	{'age': 30, 'phone': '+380971234567'}
	>>>

Можна об'єднувати більше двох словників:

	>>> d1 = {'a': 1}
	>>> d2 = {'b': 2}
	>>> d3 = {'c': 3}
	>>> d1 | d2 | d3
	{'a': 1, 'b': 2, 'c': 3}
	>>>

Існує також оператор присвоєння `|=`, який оновлює лівий операнд:

	>>> d1 = {'a': 1, 'b': 2}
	>>> d2 = {'b': 3, 'c': 4}
	>>> d1 |= d2
	>>> d1
	{'a': 1, 'b': 3, 'c': 4}
	>>> d2
	{'b': 3, 'c': 4}
	>>>

Оператор `|=` аналогічний методу `update()`:

	>>> d1 = {'a': 1, 'b': 2}
	>>> d2 = {'b': 3, 'c': 4}
	>>> d1.update(d2)  # еквівалентно d1 |= d2
	>>> d1
	{'a': 1, 'b': 3, 'c': 4}
	>>>
