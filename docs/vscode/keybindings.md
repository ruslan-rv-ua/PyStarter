## Комбінації клавіш за замовчуванням

Далі згруповані по категоріям "вбудовані" у `VS Code` комбінації клавіш. 

У кожній таблиці комбінації клавіш розташовано від більш до меньш вживаних або ж корисних, 
на думку автора.

### Загальні

| Комбінація клавіш | Команда                             | Пояснення                                                                                                        |
| ----------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Ctrl+Shift+P, F1  | Показати палітру команд             | Відкриває палітру команд, де можна шукати та виконувати різні команди редактора                                  |
| Ctrl+P            | Швидке відкриття, перейти до файлу… | Відкриває поле швидкого відкриття, де можна ввести назву файлу для швидкого доступу до нього                     |
| Ctrl+,            | Користувацькі налаштування          | Відкриває файл налаштувань користувача, де можна змінити різні параметри редактора                               |
| Ctrl+K Ctrl+S     | Комбінації клавіш                   | Відкриває файл комбінацій клавіш, де можна змінити або додати нові комбінації клавіш для різних команд редактора |
| Ctrl+Shift+N      | Нове вікно/екземпляр                | Створює нове вікно або екземпляр редактора                                                                       |
| Ctrl+Shift+W      | Закрити вікно/екземпляр             | Закриває поточне вікно або екземпляр редактора                                                                   |

| ----------------- | -------------------------------- | ------------------------------------------------------------ |

| Ctrl+Shift+\      | Перейти до відповідної дужки     | Переходить до відповідної дужки для поточної позиції курсора |

| Ctrl+Shift+]      | Розгорнути область               | Розгортає згорнутий код в поточній області                   |

| Ctrl+K Ctrl+U     | Видалити коментар з рядка        | Видаляє коментар з поточного рядка                           |
| Shift+Alt+A       | Перемкнути блоковий коментар     | Додає або видаляє блоковий коментар для виділеного коду      |

| Shift+Alt + ↓ / ↑ | Копіювати рядок вгору/вниз       | Копіює поточний рядок вгору або вниз                         |
| Ctrl+Shift+K      | Видалити рядок                   | Видаляє поточний рядок                                       |
| Ctrl+Shift+Enter  | Вставити рядок зверху            | Вставляє новий рядок перед поточним рядком                   |
| Ctrl+] / [        | Збільшити/зменшити відступ рядка | Збільшує або зменшує відступ поточного рядка                 |

### Пошук і заміна

| Комбінація клавіш | Команда                                                          | Пояснення                                                                                  |
| ----------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Ctrl+F            | Знайти                                                           | Відкриває панель пошуку для знаходження тексту в поточному файлі                           |
| Ctrl+H            | Замінити                                                         | Відкриває панель заміни для заміни тексту в поточному файлі                                |
| F3 / Shift+F3     | Знайти наступне/попереднє                                        | Знаходить наступне або попереднє входження тексту в поточному файлі                        |
| Alt+Enter         | Вибрати всі входження збігу пошуку                               | Вибирає всі входження тексту, що збігаються з пошуком, у поточному файлі                   |
| Ctrl+D            | Додати вибір до наступного збігу пошуку                          | Додає наступне входження тексту, що збігається з пошуком, до виділення                     |
| Ctrl+K Ctrl+D     | Перемістити останній вибір до наступного збігу пошуку            | Переміщує останній виділений текст до наступного входження тексту, що збігається з пошуком |
| Alt+C / R / W     | Перемикач регістрозалежності / регулярних виразів / цілого слова | Перемикає режим пошуку між регістрозалежним, регулярними виразами та пошуком цілих слів    |
