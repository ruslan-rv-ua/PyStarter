# Комбінації клавіш

бла бла інтро

### Загальні

| Комбінація клавіш | Пояснення |
| --- | --- |
| Ctrl+Shift+P, F1 | Показати палітру команд |
| Ctrl+P | Швидке відкриття, перейти до файлу… |
| Ctrl+Shift+N | Нове вікно/екземпляр |
| Ctrl+Shift+W | Закрити вікно/екземпляр |
| Ctrl+, | Користувацькі налаштування |
| Ctrl+K Ctrl+S | Комбінації клавіш |

### Редагування

| Комбінація клавіш | Пояснення |
| --- | --- |
| Ctrl+X | Вирізати рядок (порожній вибір) |
| Ctrl+C | Копіювати рядок (порожній вибір) |
| Alt+ ↑ / ↓ | Перемістити рядок вгору/вниз |
| Shift+Alt + ↓ / ↑ | Копіювати рядок вгору/вниз |
| Ctrl+Shift+K | Видалити рядок |
| Ctrl+Enter | Вставити рядок знизу |
| Ctrl+Shift+Enter | Вставити рядок зверху |
| Ctrl+Shift+\ | Перейти до відповідної дужки |
| Ctrl+] / [ | Збільшити/зменшити відступ рядка |
| Home / End | Перейти до початку/кінця рядка |
| Ctrl+Home | Перейти до початку файлу |
| Ctrl+End | Перейти до кінця файлу |
| Ctrl+↑ / ↓ | Прокрутити рядок вгору/вниз |
| Alt+PgUp / PgDn | Прокрутити сторінку вгору/вниз |
| Ctrl+Shift+[ | Скласти (згорнути) регіон |
| Ctrl+Shift+] | Розгорнути (розкласти) регіон |
| Ctrl+K Ctrl+[ | Скласти (згорнути) всі підрегіони |
| Ctrl+K Ctrl+] | Розгорнути (розкласти) всі підрегіони |
| Ctrl+K Ctrl+0 | Скласти (згорнути) всі регіони |
| Ctrl+K Ctrl+J | Розгорнути (розкласти) всі регіони |
| Ctrl+K Ctrl+C | Додати коментар до рядка |
| Ctrl+K Ctrl+U | Видалити коментар з рядка |
| Ctrl+/ | Перемкнути коментар рядка |
| Shift+Alt+A | Перемкнути блоковий коментар |
| Alt+Z | Перемкнути перенесення слів |
