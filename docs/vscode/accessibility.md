# Доступність

Visual Studio Code має багато функцій, які допомагають зробити редактор доступним для всіх користувачів:

- Збільшення елементів інтерфейса та висококонтрастні кольорові схеми
- навігація виключно за допомогою клавіатури (використання без миші)
- редактор оптимізовано для скрінрідерів

## Допомога з доступністю

Команда **Open Accessibility Help** (`Alt+F1`) відкриває меню допомоги на основі поточного контексту. 
Застосовується до редактора, терміналу, notebook, чату у боковій панелі та вбудованого в редактор чату.

## Навігація клавіатурою

`VSCode` надає вичерпний список команд у **палітрі команд (Command Palette)**. 

Натисніть `Ctrl+Shift+P`, а потім введіть ім'я команди (наприклад, 'git'), щоб відфільтрувати список команд.

`VSCode` має вбудовані комбінації клавіш для багатьох команд. 
Також можна встановити власні у відповідному редакторі **Комбінації клавіш (Keyboard Shortcuts)** (`Ctrl+K Ctrl+S`).

Для швидкої навігації по частинам інтерфейса використовуються команди **Focus Next Part** (`F6`) і **Focus Previous Part** (`Shift+F6`).

### Виділення текста

Для полегшення виділення текста існують наступні команди: 

- **Встановити початок виділення (Set Selection Anchor)** (`Ctrl+K Ctrl+B`)
- **Виділити текст до поточної позиції курсора (Select From Anchor to Cursor)** (`Ctrl+K Ctrl+K`)
- **Зняти виділення (Cancel Selection Anchor)** (`Escape`)

## Навігація клавішею `Tab`

Для навігації по основним інтерфейсним елементам використовуються клавіші `Tab` та `Shift+Tab`. 
Елемент, на якому в даний момент знаходиться фокус, візуально виділяється.

Щоб уникнути надмірної кількості "зупинок" при навігації клавішею `Tab` 
деякі інтерфейсні елементи, наприклад такі як панелі інструментів та списки вкладок, 
мають лише одну "точку фокусування". 
Коли фокус попадає на такі елементи подальша навігація всередині цих елементів відбувається клавішами зі стрілками.

За замовчуванням, натискання клавіші `Tab` у редакторі початкового кода вставляє символ табуляції 
(або пробіли, в залежності від відповідних налаштувань) 
і не переміщує фокус на наступний елемент інтерфейса. 
Такий режим називається **захоплення клавіші `Tab` (Tab trap)**. 
Перемикати `Tab trap` можна за допомогою `Ctrl+M` або ж команди **Toggle Tab Key Moves Focus**.

Для файлів відкритих у режимі "лише для читання" режим `Tab trap` не активується.

`Tab trap` також активується в інтегрованому терміналі. 
Поведінку за замовчуванням для цієї функції можна налаштувати за допомогою `editor.tabFocusMode`. 

## Екранні читачі

VS Code підтримує наступні скрінрідери:

- Windows: NVDA та JAWS
- macOS: VoiceOver
- Linux: Orca

Для NVDA рекомендується залишатися в режимі редагування та використовувати гарячі клавіші для навігації, замість використання режиму перегляду.

Дії **Go to Next/Previous Error or Warning** (`F8` та `Shift+F8`) 
дозволяють скрінрідерам оголошувати повідомлення про помилки та попередження.

## Доступний перегляд

Команда **Open Accessible View** (`Alt+F2`) відкриває доступний перегляд для 
підказок, повідомлень, виводу термінала, `Jupyter Notebook`. 
У цьому режимі можна переглядати текст виконуючи навігацію як у звичайному редакторі, виділяти та копіювати текст.


Деякі функції, такі як згортання та міні-карта (огляд коду), вимкнені, коли використовується режим екранного читача. Ви можете контролювати, чи використовує VS Code режим екранного читача, за допомогою параметру **Editor: Accessibility Support** (`editor.accessibilitySupport`) і значеннями `on`, `off` або значенням за замовчуванням `auto`, яке автоматично виявляє екранний читач за допомогою запиту до платформи.

## Звукові підказки

Звукові підказки вказують, чи має поточний рядок редактора певні маркери, 
такі як: помилки, попередження, точки зупину, згорнуті текстові області та інші.
Вони відтворюються, коли курсор переміщується на рядок з маркером або додається маркер до поточного рядка. 
Налаштувати звукові сигнали можна за допомогою параметрів `accessibility.signals.*`.

Команда **Help: List Signal Sounds** перелічує всі доступні звуки, дозволяє почути кожен, коли ви переміщуєтеся списком, і дозволяє налаштувати їхній статус (увімкнено/вимкнено).
