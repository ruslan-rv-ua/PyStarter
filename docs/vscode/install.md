# Встановлення

Процесс установки VSCode сам по собі не викликає труднощів. 
Необхідно завантажити і запустити інсталятор, потім дотримуватись підказок у діалогових вікнах.

Далі ж пропонується встановлення VSCode для слухачів даного навчального курса. 

Особливості:

* "тихе" встановлення без жодних діалогових вікон
* встановлення в теку "`C:\vscode`" (для встановлення і подальших оновлень без прав адміністратора)
* готовий конфігураційний файл з мінімальними налаштуваннями `VSCode` для користувачів скрінрідерів

### Завантаження інсталятора

Перейдіть на [сторінку завантаження VSCode](https://code.visualstudio.com/download#).

Необхідний тип інсталятора — `System Installer`. 
Посилання для завантаження для користувачів скрінрідерів буде звучати приблизно так:

    Windows System install 64-bit x64

Після активації посилання через короткий проміжок часу сторінка у браузері оновиться і буде запропоновано завантажити інсталятор.

Файл інсталятора в залежності від завантаженої версії буде носити ім'я схоже на:

    VSCodeSetup-x64-1.88.1.exe

У подальших інструкціях буде використано саме таке ім'я файла.

### Встановлення

Відкрийте термінал. 

Перейдіть у теку, куди було завантажено інсталятор, наприклад:

    cd C:\downloads

Виконайте у терміналі наступну команду:

    VSCodeSetup-x64-1.88.1.exe /VERYSILENT /NORESTART /DIR="C:\vscode" /MERGETASKS=!runcode

Через деякий час (плюс-мінус хвилина) процес інсталяції завершиться, 
у терміналі з'явиться підказка операційної системи.

Зараз закрийте поточний термінал.

### Початкові налаштування

Для швидкого старта у використанні VSCode пропонується швидкий спосіб налаштування цього редактора.

Серед запропонованих налаштувань:

- увімкнено підтримку скрінрідерів
- увімкнено автооновлення редактора та розширень
- увімкнено автозбереження файла що редагується коли редактор втрачає фокус
- встановлено термінал за замовчуванням на `cmd` замість `PowerShell`
- вимкнено телеметрію (збір даних користувача)
- вимкнено інтерфейсні елементи які є "неважливими" для невізуального використання редактора
- вимкнено "зайві" візуальні ефекти
- вимкнено деякі активності редактора які спричиняють появу запитань "зайвих" для початківця

Щоб застосувати вказані налаштування виконайте наведені нижче дії.

У файловому менеджері відкрийте теку:

    c:\Users\<username>\AppData\Roaming\Code\User\

де `<username>` — ім'я користувача Windows.

У цій теці створіть текстовий файл з наступним ім'ям:

    settings.json

Вставте як текст файла наступне:

```json
{
    "editor.accessibilitySupport": "on",
    "workbench.colorTheme": "Default High Contrast",
    "workbench.reduceMotion": "on",
    "update.mode": "start",
    "files.autoSave": "onWindowChange",
    "workbench.startupEditor": "none",
    "terminal.integrated.hideOnStartup": "always",
    "security.workspace.trust.startupPrompt": "never",
    "breadcrumbs.enabled": false,
    "files.insertFinalNewline": true,
    "terminal.explorerKind": "external",
    "editor.minimap.enabled": false,
    "editor.cursorBlinking": "solid",
    "telemetry.telemetryLevel": "off",
    "editor.stickyScroll.enabled": false,
    "explorer.decorations.colors": false,
    "workbench.editor.decorations.colors": false,
    "search.decorations.colors": false,
    "workbench.tree.enableStickyScroll": false,
    "terminal.integrated.defaultProfile.windows": "Command Prompt",
    "security.workspace.trust.enabled": false
}
```

Збережіть та закрийте цей файл.

Тепер редактор `VSCode` налаштовано для використання початківцями.

З часом, коли ви добре оволодієте цим інструментом для розробки програмного забезпечення, 
ви зможете виконати налаштування під свої потреби та на свій смак.
