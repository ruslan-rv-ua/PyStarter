Poetry

Важливо!

Інструменти для Python розвиваються досить стрімко. Ця стаття актуальна на момент останнього оновлення сайта.

Poetry — це інструмент для керування проектами на Python, який надає наступні можливості:

  • керування залежностями з відтворюваними встановленнями та резолвером конфліктів
  • автоматичне керування віртуальними середовищами
  • збірка та публікація пакетів

Встановлення

Установка Poetry виконується дуже просто як на Unix-системах:

curl -sSL https://install.python-poetry.org | python3 -

Так і на Windows:

(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | py -

Далі, залежно від вашої системи, потрібно додати відповідну директорію до PATH:

# Linux, MacOS, WSL
$HOME/.local/bin

# Windows
%APPDATA%\roaming\python\scripts

Перезавантажуємо термінал і перевіряємо правильність встановлення:

poetry --version

Створення проєкта

Для створення проекта з нуля скористаємося командою new:

poetry new my-project

При виконанні цієї команди Poetry створить папку з наступною структурою:

my-project
    my_project\
    tests\
    README.md
    pyproject.toml

Якщо ми хочемо почати використовувати Poetry у вже існуючому проекті, нам допоможе команда init:

cd my-project2
poetry init

Далі Poetry задасть нам кілька питань про наш проект (назва пакету, версія, опис, ліцензія та підтримувані версії Python), а також запропонує в інтерактивному режимі вказати залежності.

Віртуальні оточення

Команди new та init не створюють віртуальні середовища. При першому виконанні команд, пов'язаних з встановленням залежностей, Poetry створює віртуальне середовище, вибравши базовий інтерпретатор за наступною логікою:

  • Poetry перевіряє, чи вже активоване яке-небудь віртуальне середовище. Якщо так, то воно буде використовуватись.
  • Якщо жодне віртуальне середовище не активоване, то Poetry спробує використати Python, який був використаний при встановленні Poetry.
  • Якщо версія Python з попереднього кроку несумісна з версією, вказаною в pyproject.toml, то Poetry попросить явно активувати потрібну версію.

Рекомендується вказати правильний базовий інтерпретатор, виконавши в папці проекту наступну команду:

poetry env use python3.12  # якщо python3.12 є в PATH
poetry env use /path/to/python  # можна вказати полный шлях до Python

За замовчуванням Poetry створює віртуальні середовища у папці {cache_dir}/virtualenvs. Якщо ви хочете, щоб віртуальне середовище знаходилося у папці проекту, ви можете виконати наступну команду: 

poetry config virtualenvs.in-project true

Тепер створюване віртуальне середовище буде розташовуватися у папці .venv в корені проекта.

Щоб активувати віртуальне середовище, використовуйте команду:

poetry shell

Деактивувати віртуальне середовище:

deactivate

Деактивувати віртуальне середовище та закрити сесію термінала:

exit

pyproject.toml та poetry.lock

pyproject.toml — це файл, який містить всю інформацію про проект: метадані (назва, версія і т.д.) та залежності, а також може містити налаштування інших інструментів.

poetry.lock — файл містить усі залежності проекту з зафіксованими версіями і формується автоматично. Не редагуйте цей файл вручну!

Розглянемо вміст файла pyproject.toml:

  • [tool.poetry] — метадані проекта:
    • name — назва проекта. Має бути валідною згідно PEP 508
    • version — версія проекта. Має бути валідною згідно PEP 440
    • description — короткий опис проекта
    • license — ліцензія
    • authors — автори проекту у форматі name <email>. Повинен бути присутній принаймні один автор.
    • решту специфікаторів можна знайти у документації, вони не є обов'язковими.
  • [tool.poetry.dependencies] — містить версію Python та основні залежності проекта (так звану головну групу).

У PEP-517 було представлено стандартний спосіб визначення альтернативних систем збірки для проектів Python. Poetry сумісний з PEP-517 і використовує poetry-core для збірки, що вказано в розділі [build-system]:

[build-system]
requires = ["poetry-core"]
build-backend = "poetry.core.masonry.api"

Багато інструментів Python підтримують конфігурацію через pyproject.toml. Наприклад isort і mypy:

[tool.isort]
line_length = 120
...
force_grid_wrap = 2

[tool.mypy]
python_version = 3.12
...
follow_imports = "skip"

Встановлення та видалення пакетів

Для додавання пакетів до проекту використовуємо команду poetry add:

poetry add fastapi

У розділі [tool.poetry.dependencies] з'явилася наша залежність:

[tool.poetry.dependencies]
python = "^3.12"
fastapi = "^0.110.0"

Також є можливість встановити залежності з git-репозиторія, локальних та віддалених файлів і папок.

Групи залежностей (надалі просто групи) містять необов'язкові залежності, які використовуються лише під час розробки. Встановити залежності з груп можна лише за допомогою Poetry. Кожен проект містить одну неявну обов'язкову групу main, яка знаходиться в розділі [tool.poetry.dependencies].

Установка в групу виконується наступним чином:

poetry add --group test pytest

Вище ми встановили пакет pytest в групу test.

Група разом залежністю з'явилася в pyproject.toml:

[tool.poetry.group.test.dependencies]
pytest = "^8.1.1"

Щоб встановити додані залежності:

poetry install

Команда install виконує наступну послідовність дій:

  • читає файл pyproject.toml
  • якщо існує файл poetry.lock, то версії залежностей беруться з нього. Якщо його не існує, Poetry виконає розрішення залежностей і створить його
  • встановлює залежності

Для видалення будь-якої залежності можна скористатися командою:

poetry remove fastapi
